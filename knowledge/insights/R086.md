title: Privileged server credentials skip the database rules
areas: [AUTHZ]
checks: [AUTHZ-18]
---
**Summary.** Database security rules usually protect only direct client access. Backend functions that connect with an admin or service-role credential bypass those rules entirely, so they can read and write every collection, row and field. If such a function takes a collection name, table or document ID from the request and queries with it, the caller can reach anything. Each privileged function must validate its inputs, scope every query to the signed-in caller, and be listed with the data it is allowed to touch.

**Takeaways**
- Client rules end where privileged server code begins
- Never build a query path from request values on an admin connection
- Keep a list of privileged functions and what each may read and write
