title: Most agent breaches are key-handling failures
areas: [SEC]
checks: [SEC-3, SEC-4, SEC-5]
---
**Summary.** Headlines about rogue agents usually describe ordinary credential failures: keys stored on a hosting platform that was breached, keys saved inside a tool that lost them, users handing their own passwords to agents, and credentials left lying around. The fix is plain engineering. Keep every key in a vault you control, make keys short-lived and scoped to one job, give agents read-only access by default, and do not let anything in the stack update until its version is pinned and checked.

**Takeaways**
- Treat key storage as the main agent risk.
- Agents start read-only and earn write access.
- Pin and check every dependency update.
