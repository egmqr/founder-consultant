title: Agent skills and prompts go stale when the model changes
areas: [HAR, MOD]
checks: [HAR-14]
---
**Summary.** Saved skills, prompts and rules files are written against one model version. Months later they still name syntax, limits and workarounds the current model no longer needs, and that dead guidance crowds the context and anchors the agent to old behaviour. Review every loaded skill when the model changes, load only the skills the current task needs, and measure the difference rather than assuming more context helps.

**Takeaways**
- Each skill records the model version it was written and last checked against
- Skills naming removed limits, old syntax or workarounds are rewritten or retired
- Skills load per task, not all at once
- Compare quality, speed and accuracy with every skill loaded versus only the relevant ones
