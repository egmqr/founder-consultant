title: Admin consoles need real auth, throttled sign-in and an audit trail
areas: [AUTHZ, EVI]
checks: [AUTHZ-1, EVI-5]
---
**Summary.** Generated admin panels often sit at a guessable path with no login because the builder assumed only the owner would find them; automated scanners find those paths within days. Every admin page and route needs a verified session with an explicit admin role, sign-in attempts need rate limits, and every admin sign-in and change needs a record of who did what and when, or a past intrusion can never be scoped.

**Takeaways**
- No admin page renders, and no admin route answers, without an admin-role check on the server
- Admin sign-in is rate-limited; an obscure path is a bonus, never the control
- Admin sign-ins and changes are logged with actor, time, target and before/after values, in storage admins cannot edit
