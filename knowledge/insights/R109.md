**Summary.** When every call goes to the most capable model and resends the same instructions and context, the bill is high for no gain. Route routine work (formatting, parsing, lookups) to the cheapest model that gives equivalent output. Put repeated system prompts and project context in the provider's prompt cache and watch the cache-read share; a low share means nothing is being reused. Review a weekly breakdown by workflow, model and token type (input, output, cache read, cache write), give each workflow a budget, and flag spikes over its baseline. A monthly invoice shows what was spent; a weekly breakdown shows where to cut.

**Takeaways**
- Each workflow is tagged so spend can be attributed to it
- Repeated context uses prompt caching; cache-read share is tracked
- Weekly cost review per workflow, model and token type, with a per-workflow budget and spike alert
- Routine tasks go to cheaper models proven equivalent on the task
