title: Don't hand out your API schema
areas: [SEC]
checks: [SEC-15]
---
**Summary.** Query-language APIs often ship with schema introspection on, which is handy in development and gives an attacker a full map of every type, field and action in production. With that map they can craft deeply nested queries that pull huge amounts of data or exhaust the server in one request. Even with introspection off, "did you mean" field suggestions and detailed errors let them rebuild the schema piece by piece. Turn introspection and suggestions off in production, cap query depth and cost, and return generic errors.

**Takeaways**
- Introspection off in production
- Every request has a depth and cost limit
- No field suggestions or schema details in production errors
