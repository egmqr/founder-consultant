title: Third-party scripts run with your app's full privileges
areas: [SEC]
checks: [SEC-21]
---
**Summary.** A one-line embed for chat, analytics, reviews or A/B testing runs with the same rights as the app's own code: it can read every form field, keystroke, cookie and token on the page it loads on. AI builders add such tags casually and on every page. Keep an inventory of external scripts and the pages they load on, keep them off sign-in, payment, account and admin pages, and use a Content Security Policy that only allows listed script origins and blocks inline injection.

**Takeaways**
- Know every external script, what it can reach and where it loads
- No third-party script on pages that handle credentials, payments or admin functions
- A CSP script allowlist turns an unlisted script into a blocked one
