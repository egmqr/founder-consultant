title: User input in emails is plain text
areas: [SEC]
checks: [SEC-16]
---
**Summary.** Transactional emails often drop a user's name or message straight into an HTML template. If that field accepts markup, an attacker can plant a fake button or link, and the result goes out from your own verified domain, passing every sender check, so it looks fully legitimate. Escape every user value before it enters a template, never use the template's raw-HTML path for user content, and test each template by submitting angle brackets, links and script tags in every field.

**Takeaways**
- Template values are escaped by default; raw HTML only for your own markup
- Every email template is tested with markup in every user field
- Your sending domain's reputation is at stake, not just one message
