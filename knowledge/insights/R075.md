title: Send the browser only the fields it shows
areas: [AUTHZ]

---
**Summary.** Server-rendered components and API handlers often pass a whole database row along because the query is simpler. The screen shows three fields, but every field is serialized into the response the browser receives: password hashes, internal role flags, billing tokens. Anyone can read that payload in the network tab and scrape it at scale. The same leak happens with live subscriptions that stream every row and leave the filtering to the client. Select only the fields a screen renders, pass a small purpose-built object across each boundary, and filter by owner in the query itself before data leaves the server.

**Takeaways**
- Query the fields a screen renders, never the whole row
- Pass a minimal object at each component or API boundary
- Hidden in the UI is still sent; read the raw payload
- Live subscriptions filter by the signed-in user on the server; test with two accounts open side by side
