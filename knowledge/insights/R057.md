title: Lock down cloud storage buckets by default
areas: [SEC]
checks: [SEC-6, SEC-7]
---
**Summary.** Generated infrastructure often makes a storage bucket publicly readable so images load without errors, while the same bucket also holds backups, exports or config files. Keep public assets in their own bucket and make everything else private, served through expiring signed links. Avoid bucket names that reveal company, environment or contents, since attackers scan common naming patterns. Turn on access logging with alerts for unusual download volume or unexpected networks, so a leak is visible instead of silent.

**Takeaways**
- Separate public assets from private data in different buckets
- Serve private files only through expiring signed links
- Enable access logging and alert on unusual downloads
