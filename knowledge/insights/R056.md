title: Expire tokens, rotate refresh, recheck roles live
areas: [AUTHZ]
checks: [AUTHZ-2, AUTHZ-6]
---
**Summary.** Generated authentication code often signs tokens with no expiry, so a token leaked through logs, devices or backups works forever, even after a password change. Give access tokens a short lifetime of around fifteen minutes, keep refresh tokens in HttpOnly cookies with a limited lifetime, rotate them on each use, and revoke the whole token family when a used refresh token reappears. Do not trust a role stored inside the token for elevated actions; check the current role in the database so demotions take effect immediately.

**Takeaways**
- Every access token has a short expiry
- Refresh tokens rotate on use and reuse revokes the family
- Elevated actions check the current role in the database
