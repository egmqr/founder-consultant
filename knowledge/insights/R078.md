title: Scheduled jobs are public buttons unless locked
areas: [AUTHZ]
checks: [AUTHZ-14]
---
**Summary.** A scheduled job hosted as an HTTP route is an ordinary endpoint on a timer. If the handler never checks the scheduler's secret, anyone who finds the URL can run cleanups, bulk emails or billing renewals on demand. Verify the secret the scheduler sends on every call and keep it in server configuration. Because a leaked secret allows repeat runs, the handler should also refuse calls that arrive faster than the schedule allows.

**Takeaways**
- Every scheduled endpoint checks the scheduler's secret before doing work
- Calls outside the expected schedule window are refused
- Jobs that send or charge are safe to run twice by accident
