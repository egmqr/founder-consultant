title: Start from recent data, cut over after shadowing
areas: [DATA, ROLL]

**Summary.** AI projects do not need every historical record cleaned first. Export a recent window, such as the last 30 days, from each core system into one database you own, stamping each row with the originating system and export date. Give each customer, product and job one permanent ID with a mapping table from every system's IDs. Run the new process in shadow beside the old one, log daily differences, and switch only after a sustained period with none.

**Takeaways**
- Recent live data beats a perfect archive.
- One permanent ID per entity, mapped from every system.
- Earn the switch with a clean shadow run.
