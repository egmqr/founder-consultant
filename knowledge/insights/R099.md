title: A self-managed server needs the hardening a managed platform used to do for you
areas: [SEC]
checks: [SEC-25]
---
**Summary.** Moving from a managed platform to a rented server moves firewalling, remote-login hardening and patching onto you, and a fresh server usually has none of it. Bots try passwords on the default remote-login port around the clock, and a database port left open is reachable by anyone. The baseline is short: key-only login with root login off, a firewall that denies all inbound traffic except the ports the app needs, and automatic security updates.

**Takeaways**
- Remote login accepts keys only; password login and direct root login are off
- Inbound firewall default is deny; only remote login, HTTP and HTTPS are open, and database ports are never public
- Security updates install automatically, and someone checks they are still running
- Do this before anything else is deployed on the server
