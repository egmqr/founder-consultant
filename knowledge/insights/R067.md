title: Verify every webhook before acting on it
areas: [AUTHZ]

**Summary.** A webhook endpoint that provisions service, upgrades plans or grants access on any well-formed POST is a command anyone can send. Payment processors and most major platforms sign their webhook payloads with a shared secret, but AI-written integrations often skip the check because the happy path works without it. Verify the signature on every provider's webhook before processing, and record processed event IDs so a captured, validly signed event can't be replayed to provision the same thing twice.

**Takeaways**
- Unsigned webhook handling is an open command line
- Verify the provider signature on every webhook route, for every provider
- Store processed event IDs and reject duplicates
