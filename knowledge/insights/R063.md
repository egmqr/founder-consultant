**Summary.** Fine-tuning open-weight models no longer needs a cluster: memory-efficient tooling lets one modern GPU handle runs that once took several (memory savings of up to 80% are claimed; industry reports cite; verify). Tools that capture dataset, base model and hyperparameters in one configuration file make a run a single command. Keep that file versioned so runs are reproducible, and use tuning for behavior and style while changing facts stay in documents.

**Takeaways**
- One GPU can fine-tune a mid-size open model
- Keep dataset, base model and settings in one versioned config
- Tune behavior; serve changing facts from documents
