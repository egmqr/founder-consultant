title: Server code can leak into the browser bundle
areas: [SEC]
checks: [SEC-19]
---
**Summary.** Frameworks that mix server functions and browser components decide what ships to the client by following imports. When a file holds both, or a browser component imports a module that touches the database, the bundler can pull connection strings and keys into the JavaScript every visitor downloads. Mark server-only modules so the build fails if browser code imports them, keep server logic in files that share no exports with rendered components, and search every production build for the values of your server environment variables.

**Takeaways**
- Every file the browser downloads is public, minified or not
- A build that fails on a bad import beats a review that might miss it
- Search the built output, not only the code you wrote, for secret values
