id: R059
date: 2026-11-19
title: Treat localhost tools as reachable; authenticate them
areas: [AUTHZ, SEC]
checks: [AUTHZ-1, SEC-9]
---
**Summary.** Internal dashboards, database consoles and dev servers built without login because they are only on localhost can still be reached. DNS rebinding lets a malicious web page make the browser talk to local services and read the answers, and servers bound to all interfaces accept connections from anyone on the same network. Bind internal and development services to the loopback address explicitly, reject requests whose Host header is not the expected value, and require authentication on every internal tool regardless of where it listens.

**Takeaways**
- Bind dev and internal services to 127.0.0.1, never 0.0.0.0
- Reject requests with an unexpected Host header
- No internal tool runs without a login
