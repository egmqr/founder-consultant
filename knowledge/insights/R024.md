title: Lock down self-hosted models behind a gateway
areas: [MOD, SEC]
checks: [MOD-4, SEC-5]
---
**Summary.** Moving to a self-hosted open-weight model does not make it safe; popular model runners ship without login, and researchers estimate many such servers sit exposed online (industry reports cite; verify). Keep the model off the public internet: private networking only, no public domain, every other port closed. Put an authenticated gateway in front with one key per app, a rate limit per key, and every request logged to storage you own. Pin exact versions of server software, gateway and weights, verify downloads, and update only after staging tests.

**Takeaways**
- Owning the model means owning its security.
- Gateway with per-app keys and limits; log every call.
