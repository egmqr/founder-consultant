**Summary.** Choosing hardware first and hoping a model fits is backwards. Test the real task against a few open-weight models and keep the smallest one that passes consistently. Then size memory: roughly two bytes of GPU memory per parameter at full precision, much less when quantized to four bits, plus headroom for long context and concurrent users. Before buying, rent that class of GPU for a week on the real workload and track speed and cost per task.

**Takeaways**
- Job picks model, model picks hardware.
- Budget memory for full context and concurrent users, not just weights.
- Rent and measure for a week before buying.
