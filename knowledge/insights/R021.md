title: Stream every stage to cut voice lag

**Summary.** Callers hang up after a few seconds of silence, and a voice agent is three systems in a row, each waiting for the last. Switch speech-to-text to streaming with voice activity detection so it catches the end of a turn immediately. Stream model output into text-to-speech one sentence at a time rather than waiting for the full answer. Run all three stages on one machine to remove network hops, and let a small fast model handle conversation while harder questions go to a larger one.

**Takeaways**
- Batch stages add dead air; stream them.
- Co-locate stages and use a small model for small talk.
