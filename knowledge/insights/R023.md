title: Plan a phased exit from vendor AI

**Summary.** Using big vendor AI is not the mistake; using it with no exit is. Move in phases, each useful alone: keep your own copy of everything fed to vendor models, add a layer you control between the business and those models, run sensitive proprietary work on a model on hosting you manage, and buy hardware only when cost or regulation demands it. Start at phase zero by listing every platform, account, agent with access and employee holding business knowledge.

**Takeaways**
- The risk is having no exit, not using vendor AI.
- Start with an inventory of where knowledge lives.
