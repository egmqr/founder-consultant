title: Segment services so one breach stays contained
areas: [SEC]
checks: [SEC-8]
---
**Summary.** AI-generated deployments often place every service on one shared network where anything can call anything. A flaw in a low-value tool then becomes a path to admin APIs and the production database, especially when credentials sit in readable environment variables. Limit each service to the exact peers it needs, require service tokens or mutual TLS on every internal call instead of trusting network location, and give each container only the network reach and database rights its job requires, such as read-only where it never writes.

**Takeaways**
- Each service may reach only the services it needs
- Internal calls need authentication, not just a private network
- Read-only credentials and no internet egress unless required
