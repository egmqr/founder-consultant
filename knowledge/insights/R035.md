title: Give every agent an identity and owner
areas: [EVI, HAR]
checks: [EVI-1, HAR-7, HAR-8, HAR-10]
---
**Summary.** Most agents run on someone's personal login or a shared key, so when that person leaves, nobody knows what the agent can still reach. Give each agent its own service account and key, and a named person (not a department) as owner who decides what it may touch. Remove every permission beyond that decision: an agent that drafts emails need not send them. Log every action to storage you own, build and test a stop command, and retire agents idle for 30 days because idle agents still hold live keys.

**Takeaways**
- If nobody owns the agent, the agent owns the risk.
- Permissions match the owner's decision, nothing more.
- Idle agents hold live keys.
