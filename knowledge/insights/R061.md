title: Keep server admin panels off the public internet
areas: [SEC]
checks: [SEC-6]
---
**Summary.** AI-run server setups often follow install guides that open a hosting control panel port to every address. Such panels control databases, domains, certificates and files, so a brute-forced password or panel flaw equals root access, and automated scanners find default ports and paths within minutes. Restrict the panel port to a VPN or fixed address list with firewall rules, turn on two-factor login right after installation, and put the panel behind a reverse proxy so the raw port is blocked from the internet.

**Takeaways**
- Admin panels reachable only via VPN or address allowlist
- Enable two-factor login immediately after install
- Block the panel's default port from the internet
