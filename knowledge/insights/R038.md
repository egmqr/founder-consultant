title: Seal the agent sandbox - network, rights, keys
areas: [MOD, SEC]
checks: [MOD-5, SEC-4]
---
**Summary.** If a model or agent can reach the internet, it can download tools and send out your data, so it is not a sandbox. Run agents in a container with networking off, and if one outside service is truly needed, allow only that host and deny the rest, with a test proving it. Run as a regular user, never an administrator, with a read-only filesystem except one scratch folder and no view of the host. Issue keys that open one system for one job and expire within an hour.

**Takeaways**
- Network off by default, allowlist the exception.
- Non-admin user, read-only filesystem.
- Keys inside the box expire within an hour.
