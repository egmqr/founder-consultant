title: Contain models whose makers report nothing
areas: [MOD]

**Summary.** Every model maker has agent incidents, but only some disclose them; no disclosure does not mean no incidents. Open-weight models you run yourself will never send you an incident report, so the burden is yours: test the model on your own workloads, run it in a contained environment, log what it does, and assume it can take actions nobody documented. Fear and silence are both messaging strategies; neither is a security strategy.

**Takeaways**
- Zero disclosed incidents is not zero incidents.
- Self-hosted models need your own containment and logging.
- Assume undocumented capabilities.
