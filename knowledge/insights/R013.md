**Summary.** Know-how held only in an assistant's built-in memory leaves when the tool changes terms, raises prices or closes the account. Keep it in plain files any model can read. Organize by function (clients, operations, pricing, decisions, AI instructions, ownership), one topic per file, so drafts are not mistaken for decisions. Every decision file records what was decided, when and why. Hunt down conflicting facts, such as two prices, merge them into one authoritative file, and keep the folder under version control.

**Takeaways**
- One topic per file, organized by function, not by date.
- Record the decision, its date and its reason.
- Resolve conflicting facts into one versioned file.
