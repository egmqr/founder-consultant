**Summary.** Pick the job, the model, the memory, then the machine. A rough rule of thumb is a little over half a gigabyte of memory per billion parameters at 4-bit, plus room for context (industry reports cite; verify). Rent hardware for a week of real work first, and compare buying against a year of rental. A local AI box is still a server: keep it off the internet, require sign-in in front of the model, and pin tested runtime and model versions before any real file goes in.

**Takeaways**
- Job, model, memory, then machine.
- Rent before you buy.
- A box on your desk is a server you must secure.
