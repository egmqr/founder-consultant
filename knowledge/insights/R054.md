**Summary.** Large companies rewriting legacy code with AI are setting a rule that every piece of code must have human provenance: AI writes it, a person owns it. Bolting AI tools onto an old system inherits its shortcuts, so rebuilding with AI can make sense, but only with an accountable human for every change and the work led by someone experienced. Such rebuilds are bets in progress, not proven results.

**Takeaways**
- AI-written code still needs a human owner.
- Experience, not enthusiasm, should lead an AI rebuild.
