title: Review and block agent artifacts before commit
areas: [HAR, SEC]
checks: [HAR-12, SEC-2]
---
**Summary.** AI coding assistants take screenshots, logs and traces to understand context and check their work, and with default settings those files can be committed alongside code. Researchers reported thousands of private screenshots from hundreds of companies, showing billing screens, credentials and dashboards, in public repositories (industry reports cite; verify). The tools behaved as designed; the configuration was the failure. Keep agent artifacts outside the repository or ignored, scan every commit for images and captured data, and confirm each repository's visibility before agents push.

**Takeaways**
- Agent screenshots and logs can hold customer data and keys
- Ignore agent artifact folders and scan commits for them
- Check repository visibility before an agent pushes
