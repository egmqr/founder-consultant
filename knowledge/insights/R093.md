title: Unindexed queries get slower and costlier as data grows
areas: [DATA]
checks: [DATA-8]
---
**Summary.** Generated queries work on small test data and quietly scan the whole table on every request. Cost and latency grow with the data until the host throttles or bills the app, and nobody sees it coming because nothing measures it. Index the columns each query filters, joins and sorts on, select only the fields the feature uses, and log queries above a time threshold so the slow ones are visible.

**Takeaways**
- Every frequent query filter and sort has an index, checked against the query plan
- Queries select named fields, not whole rows
- Slow-query logging with a threshold, reviewed with call counts and cost
- Measure before and after on production-sized data
